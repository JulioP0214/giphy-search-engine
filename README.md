# Giphy Search Engine

## Overview

The Giphy Search Engine is a simple website that allows users to search for GIFs by entering a keyword. The website uses the Giphy API to retrieve GIF results and display them on the page.

## How to Use

1. Open the website.
2. Enter a keyword into the search box.
3. Click the Search button.
4. GIFs related to the search term will appear in the results section.

## Functionality

- Users can search for GIFs using keywords.
- The website connects to the Giphy API.
- Search results are displayed dynamically using JavaScript.
- GIFs are displayed in a Flexbox-based layout.
- The page includes responsive styling for mobile screens.
